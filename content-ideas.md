# Content ideas queue

One topic per line, plain text, in the order you want them written.
The automated workflow always takes the **first** line under "## Queue"
each run, writes a draft lesson from it, and moves that line down to
"## Done" in the same commit — so this file also doubles as a log of
what's been drafted and when.

Default type is a **lesson**. To draft a different type instead, prefix
the line, e.g.:
  poem: a haiku about waiting rooms

Everything else defaults to type "lesson".
